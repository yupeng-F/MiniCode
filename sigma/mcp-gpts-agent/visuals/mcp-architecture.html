以前：无统一协议

  • 每个工具单独写适配层
  • 认证方式各搞一套
  • 参数描述格式不统一
  • 错误处理各自定义
  • 换了 LLM 提供商就要重写

MCP 之后

  • 一套协议对接所有工具
  • 统一认证（OAuth 内置）
  • 统一 JSON Schema
  • 统一错误码和生命周期
  • 换任何 LLM 都无缝兼容
