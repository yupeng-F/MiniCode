# 项目目标与实施路线

## 1. 项目定位

本项目是一个基于 `LangGraph + Harness` 思想构建的 `Agentic Coding Assistant`。

它的目标不是只做一个概念 Demo，而是逐步做成一个可以：
- 理解代码仓库
- 制定开发计划
- 修改代码
- 审查代码
- 运行测试
- 在受控环境中安全执行工具

的真实可用型 coding assistant。

## 2. 这个项目为什么要做

当前项目服务于四个核心目标：

- `求职`：形成一个能展示系统设计能力、工程落地能力、Agent 构建能力的项目
- `面试`：沉淀可讲清楚的多 Agent、记忆、安全、权限、工具编排案例
- `学习`：系统熟悉 Agent 系统从架构到实现的完整链路
- `实用`：解决实际开发中理解代码、改 bug、审查、测试、安全执行等痛点

## 3. 优先要解决的真实问题

- 大仓库理解成本高，定位入口慢
- 修 bug 时上下文收集分散，容易漏看影响面
- 修改后缺少系统化审查与回归验证
- 直接让 AI 执行 shell / 改文件存在安全风险
- 长会话上下文膨胀，历史信息难以稳定复用
- 已解决的问题难以沉淀成后续可复用经验

## 4. 当前确认的顶层决策

- 智能体架构：`Master-Specialist`（主控 + 专业智能体）
- 编排内核：`LangGraph`
- 执行控制：`Harness Runtime`
- 记忆系统：`ChromaDB 向量库 + 滑动窗口压缩`
- 产品方向：`coding assistant`
- 核心角色：`Master / Explorer / Coder / Reviewer / Tester / Memory Writer`
- 安全原则：`默认只读、受控写入、高风险审批`
- 交互方式：`Web UI（FastAPI + 原生前端）`

## 5. 项目范围

### 当前优先做的

- 架构正确
- 模块边界稳定
- 核心链路可跑通
- 安全护栏先成立
- 文档可讲清楚

### 当前不追求的

- 一开始就完整复刻 Claude Code
- 一开始就上复杂多租户平台能力
- 一开始就做高度自动化的自进化记忆
- 一开始就做超大规模并行 agent team

## 6. 分阶段实施路线

### Phase 0：架构设计与框架搭建（已完成）

- 明确系统架构、模块边界、协作范式
- 建立仓库结构
- 搭建最小骨架

### Phase 1：MVP 编排闭环（已完成）

- 原版 StateGraph 线性工作流（11 节点，9 阶段状态机）
- 四种模式路由（Ask/Plan/Act/Review）
- Harness Runtime 执行链路
- 17 个测试用例通过

### Phase 2：Master-Specialist 架构改造（已完成）

- **架构改造**：
  - Master Agent 动态调度（LLM 驱动路由）
  - Specialist Agent 工具权限专精（按角色裁剪工具）
  - Coder 工具调用循环上限控制
  - 返工回路优化（Master 决策而非硬编码条件边）
- **记忆系统**：
  - ChromaDB 向量库集成
  - MemoryEntry 写入与检索
  - Context Manager 上下文裁剪
  - 滑动窗口 + LLM 摘要压缩
- **工具链增强**：
  - Tool Registry 按角色注册与分发
  - 审批流程接通（高风险工具路由到 execute_tool_approval 节点）

### Phase 3：Web 交互界面（已完成）

- FastAPI 后端 + 原生 HTML/JS/CSS 前端
- SSE 流式输出
- 工作目录选择
- 历史持久化
- Debug 面板（State/Tools/Trace/Memory/Plan）
- Markdown 渲染 + 代码高亮
- Agent 活动指示器
- 消息分区与折叠

### Phase 4：Shell 沙箱（已完成）

- subprocess 执行 + 黑名单 + 30s 超时 + 100KB 上限
- 按角色控制 run_shell 权限

### Phase 5：工程增强（已完成）

- **审批流程图接线** — `route_after_specialist` 按 risk_level 分流高风险工具到审批节点
- **Plan 去重** — `apply_decision` 跳过重复 plan
- **get_config()** — 消除 ChromaDB deprecation warning
- **Trace 事件系统** — 5 类事件插桩（task/agent/tool/approval/dispatch），Debug 面板时间线 Tab
- **Eval 评测框架** — JSON 任务定义 + 评分器 + 运行器 + 离线任务 + 报告生成
- **Audit 审计日志** — write_file/run_shell 自动 JSONL 持久化
- **UI 增强** — Markdown 渲染、Agent 可视化、消息折叠

## 7. 当前状态

所有 Phase 0-5 已全部完成。项目处于功能完备、待用户提出新需求的稳定状态。
